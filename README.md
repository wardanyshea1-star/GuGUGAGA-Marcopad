# GUGUGAGA

Gugugaga pad is a 9 key macropad with a rotary encoder, an OLED Display. It uses kmk firmware.
It’s mainly designed for playing games.

## Features:
- 3d printed case
- 1x 0.91 inch OLED Display
- EC11 Rotary encoder
- 9 Keys

## CAD Model:
Everything fits together using extended bits on the bottom piece that fit into the above piece, and  2 screws.

## Firmware Overview
This hackpad uses KMK firmware for everything.
the rotary encoder changes volume. press to pause
The 9 keys are for moving up down sideways, space and mouse functions left click ad right click. and 2 other switches for copy and paste just because its convenient. Also the oled display shows the time( for not to keep playing for too long)

# BOM
Here should be everything you need to make this hackpad

- 9x MX-style Switches
- 9x DSA Keycaps
- 2x M3x16mm screws
- 2x M3x5mx4mm heatset inserts
- 9x 1N4148 Diodes.
1x 0.91" 128x32 OLED Display
1x EC11 Rotary Encoder
1x Seeed XIAO RP2040
2 printed parts
